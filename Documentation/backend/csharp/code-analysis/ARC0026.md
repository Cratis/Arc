## Correct the marked declaration

`[Query]` expresses endpoint intent on a `[ReadModel]`. It does not make an invalid method eligible. A marked method must be ordinary, public or internal, static, and nongeneric, with value parameters and a supported read-model return shape. Plain `Task`, unsupported return types, by-reference arguments or results, and a missing read-model owner are errors. Correct the declaration or remove the marker.

Validation applies even when `RequireQueryAttribute` is false. That default retains conventional discovery: marking one method does not hide siblings or widen return eligibility.

## Resolve a duplicate name

In `RequireQueryAttribute = true` mode, two selected overloads with the same name cannot have distinct query identities. Rename one endpoint or remove its marker. An unmarked overload can remain as a helper.

See [explicit endpoint selection and migration preview](../queries/model-bound/static-methods.md#choose-endpoints-explicitly-when-a-model-has-helpers).
