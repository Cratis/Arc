---
title: "ARC0023: Generated value declared outside a command Handle method"
description: Declare generated values only on instance Handle parameters of model-bound commands.
---

## Rule

`[GeneratedValue]` belongs only on a parameter of the effective instance `Handle()` method
of a `[Command]` type. The method can be declared on a base type without `[Command]` and
inherited by the command. `Provide()` parameters, queries, MVC actions, constructors,
local functions, and other methods do not participate in generated value resolution.
Static methods and private base methods are not inherited handlers. Non-public instance
methods declared on the command satisfy this rule, matching runtime discovery.
**Default severity: Error.**

The analyzer reports a declaration if no command in the compilation uses that method
as its effective `Handle()`, unless it can be a reusable handler for a command in another
assembly. An ordinary, non-static, non-private `Handle()` on an effectively public,
non-sealed class or record is left unreported even without a local `[Command]` subclass.
All containing types must also be public; internal types are not exempted through
`InternalsVisibleTo`.

A sealed or inaccessible non-command type cannot provide that external handler.
`Provide()`, other method names, and static methods remain invalid locations.
A hidden base handler can still be valid if another local or external command uses it.

## Diagnostic example

These command excerpts assume the `CartId` declaration from
[generated values](../commands/generated-values.md) and an import of
`Cratis.Arc.Commands.ModelBound`. Compile the alternatives separately; the first
intentionally produces ARC0023.

```csharp
[Command]
public record AllocateCartId
{
    public CartId Provide([GeneratedValue] CartId cartId) => cartId;

    public CartId Handle(CartId cartId) => cartId;
}
```

## Fix

Move generation to the handler parameter:

```csharp
[Command]
public record AllocateCartId
{
    public CartId Handle([GeneratedValue] CartId cartId) => cartId;
}
```

For an ordinary service or read model dependency, remove `[GeneratedValue]` instead.
Arc resolves those dependencies through the normal Provide and dependency injection path.
